# RadioText AI — Android Beta Releases

Official distribution of **RadioText AI**, a free experimental Android app for live internet radio and speech-to-text transcription.

## Version 0.2.0 Beta
- Internet radio playback
- Russian and English recognition using Vosk
- Experimental keyword detection
- Adjustable caption text

Download: [GitHub Releases](https://github.com/OskolElkin/RadioText-AI-Releases/releases) | [itch.io](https://oskolelkin.itch.io/radiotext-ai)

**Limitations:** Speech recognition can be inaccurate, delayed, or incomplete. Station availability and capture permissions vary. TalkBack compatibility and 200% system font scaling have not been fully verified. Do not use for emergency or safety-critical communication.
