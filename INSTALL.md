# RadioText AI — установка на Android / Android installation

## Русский: как установить без регистрации

**Что это?** RadioText AI — бесплатная тестовая Android-программа: воспроизводит интернет-радио и показывает распознанную речь текстом. Поддерживаются русский и английский языки. Точность распознавания может различаться.

1. Откройте [страницу выпуска 0.2.0 Beta](https://github.com/OskolElkin/RadioText-AI-Releases/releases/tag/v0.2.0-beta).
2. Найдите раздел **Assets** (если он свернут, нажмите на него).
3. Выберите файл **RadioText-AI-v0.2.0-beta.apk**. Не выбирайте ZIP для обычной установки. Файл большой, около 145 МиБ, лучше использовать Wi-Fi.
4. Дождитесь загрузки. Откройте APK из уведомления браузера или приложения **Файлы → Загрузки**.
5. Android может спросить разрешение на установку из этого источника. Проверьте, что скачивали APK с официального GitHub проекта, и следуйте стандартным инструкциям устройства. **Не отключайте Play Protect и не игнорируйте предупреждения об опасном файле.** Если система блокирует установку, остановитесь и сообщите разработчику.
6. После установки запустите **RadioText AI**, выберите доступную интернет-радиостанцию, включите воспроизведение и дождитесь речи. Проверьте, появляется ли текст.

**Не нужна регистрация** ни на GitHub, ни на itch.io. Платить не нужно. На itch.io кнопка подписки на автора **не является** кнопкой скачивания.

Если что-то непонятно, сделайте скриншот экрана с затруднением (скройте личные данные) и опишите проблему в [обсуждении для тестировщиков](https://github.com/OskolElkin/RadioText-AI-Releases/issues/1). Для комментария на GitHub может потребоваться аккаунт; **для скачивания он не нужен**. Можно также передать отзыв человеку, который пригласил вас тестировать приложение.

**Безопасность:** это бета-версия вне Google Play. Проверочный SHA-256 APK: `550c46faae1e96dacf3da28797793726e817cca3c6e0915df5924926c9dc3338`. Не используйте приложение для экстренных сообщений.

## English: install without creating an account

RadioText AI is a free experimental Android internet-radio app that displays recognized Russian and English speech as text.

1. Open the [v0.2.0 Beta release page](https://github.com/OskolElkin/RadioText-AI-Releases/releases/tag/v0.2.0-beta).
2. Expand **Assets** if necessary.
3. Tap **RadioText-AI-v0.2.0-beta.apk** (not the ZIP archive).
4. Wait for the download, then open the APK from Downloads.
5. Review Android's installation prompt. Only proceed if you trust the official source. **Do not disable Play Protect or bypass a malware warning**; stop and report any block.
6. Launch RadioText AI, choose an available radio station, start playback, and check whether speech appears as captions.

**No account or payment is needed to download.** Following the developer on itch.io is not part of installation.

If stuck, share a screenshot without personal information. Feedback: [tester issue](https://github.com/OskolElkin/RadioText-AI-Releases/issues/1) (posting on GitHub may require signing in).

Beta limitations: captions may be inaccurate or delayed; internet radio stations may be unavailable. Not for emergency use.
